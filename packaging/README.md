# mectov — the Photoshop alternative for Linux

A native Linux image editor for layered compositions, photo retouching, and camera RAW development.

Launch mectov from your application menu or run `mectov --demo` to explore a sample composition. In a portable archive, run `bin/mectov` directly or use `scripts/install.sh` to install under `~/.local`.
